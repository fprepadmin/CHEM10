🚀 Cài đặt

Bắt đầu trong 5 bước

Yêu cầu: Node.js ≥ 18, tài khoản Firebase, Gemini API Key.

1

Clone repo & cài dependencies

Tải source code và cài đặt toàn bộ thư viện phụ thuộc.

git clone <repo-url>
cd CHEM10
npm install
2

Cấu hình Firebase

Điền thông tin project Firebase vào file cấu hình. Lấy từ Firebase Console → Project Settings → Your apps.

// firebase-applet-config.json
{
  "projectId": "your-project-id",
  "appId": "your-app-id",
  "apiKey": "your-web-api-key",
  "authDomain": "your-project.firebaseapp.com",
  "firestoreDatabaseId": "your-db-id",
  "storageBucket": "your-project.firebasestorage.app",
  "messagingSenderId": "your-sender-id"
}
3

Tạo file .env.local

Lấy Gemini API Key tại aistudio.google.com/apikey (miễn phí).

cp .env.example .env.local

# Chỉnh sửa .env.local:
GEMINI_API_KEY=your_gemini_api_key_here
APP_URL=http://localhost:3000
4

Deploy Firestore Security Rules

Thiết lập phân quyền database để bảo vệ dữ liệu đáp án.

npm install -g firebase-tools
firebase login
firebase use your-project-id
firebase deploy --only firestore:rules
5

Chạy development server

Server Express + Vite HMR chạy đồng thời tại port 3000.

npm run dev

# Mở trình duyệt: http://localhost:3000 🎉

📦 Các lệnh NPM

Lệnh Mô tả

🔐 Bảo mật

Zero Answer-Key Exposure

Hệ thống được thiết kế từ đầu để đáp án không bao giờ tiếp cận được phía client.

🛡️

Server-side Grading

Toàn bộ logic chấm điểm xử lý tại Express server. Client chỉ nhận điểm số — không nhận đáp án.

🔥

Firestore Rules Strict

Collection answerKeys chỉ đọc được bởi server. Học sinh bị deny tuyệt đối ở mức database.

🏷️

RBAC 3 tầng

Phân quyền ADMIN / TEACHER / STUDENT được kiểm tra cả phía server lẫn Firestore Rules.

🔑

Secrets qua ENV

API Keys, Firebase config không được commit vào git — chỉ tồn tại trong biến môi trường runtime.

⏱️

Kiểm tra Assignment

Server xác minh bài giao còn hiệu lực, chưa đóng, học sinh có trong danh sách trước khi chấm.

📋

Audit Log

Mọi lần chấm bài được ghi log đầy đủ — questionId, source, kết quả — để kiểm tra khi cần.
